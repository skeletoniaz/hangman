PyQt5 Hangman Game
A standalone desktop Hangman game built independently to practice Python fundamentals and object-oriented programming.

Features
Interactive Graphical User Interface (GUI) built with PyQt5.
Dynamic word selection and visual game state tracking.
Object-oriented logic structure for handling user input events.

Why it won't run directly on GitHub
This is a native desktop application that requires local installation of the Python runtime and the PyQt5 package.
